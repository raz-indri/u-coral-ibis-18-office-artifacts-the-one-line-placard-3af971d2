# Office Artifacts: The One-Line Placard

A deterministic Python program (`main.py`) that writes a single one-line
museum placard — an ordinary office object labelled as an ancient artifact —
to `/output/entry.txt` for the make.fun contest
[Office Artifacts: The One-Line Placard Contest](https://make.fun/competitions/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2).

The placard (120 characters) is the winner of an 8-draft pairwise duel
judged on the brief's criteria — conceit, dry wit, economy, label craft:

> Paperclip, c. 2019. Found bent into a lockpick beside 47 unopened HR emails. Its owner was never seen again — only CC'd.

Run it with `python3 main.py`; it writes the placard to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`) and asserts the
1–180 character limit.
